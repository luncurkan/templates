# luncurkan.dev templates

Ready-to-deploy project templates for [luncurkan.dev](https://luncurkan.dev) deployment platform.

## Available Templates

### axum-short-url

URL shortener service built with Rust and Axum.

- **Stack:** Rust, Axum 0.8, PostgreSQL, SQLx
- **Features:** Custom short codes, click tracking, stats API, web UI

### go-fiber-url-shortener

URL shortener service built with Go and Fiber.

- **Stack:** Go 1.21+, Fiber v2, HTMX
- **Features:** In-memory storage, visit tracking, reactive UI

## Usage

Deploy any template directly to luncurkan.dev or use as a starting point for your own projects.
